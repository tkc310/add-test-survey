# Specs（Playwright Test Agents）

[Playwright Test Agents](https://playwright.dev/docs/test-agents) の **planner** が出力する Markdown テスト計画を置くディレクトリです。

- 計画の例: [`task-basic.md`](./task-basic.md)
- 対応する生成テスト例: `e2e-pw-agents/task-basic.spec.ts`
- 実行手順: [`docs/playwright-test-agents.md`](../docs/playwright-test-agents.md)

既存の `e2e/`（通常の Playwright E2E）や `e2e-agent/`（TesterArmy）とは別系統です。
