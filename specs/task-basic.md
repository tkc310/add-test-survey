# タスク管理アプリ - 基本操作テスト計画

## Application Overview

このアプリは Next.js のタスク管理サンプルです。タスクの追加・完了・削除を通じて、ユニット / 統合 / E2E のテスト層を学べます。

主な機能:

- タスクの追加（入力欄 +「追加」ボタン）
- タスクの完了（チェックボックス）
- タスクの削除（削除ボタン）
- 初期表示されるデフォルトタスク

## Test Scenarios

### 1. タスクの基本操作

**Seed:** `e2e-pw-agents/seed.spec.ts`

#### 1.1 有効なタスクを追加できる

**Steps:**

1. タスク入力欄（placeholder: 「タスクを入力...」）をクリックする
2. 「Playwright Test Agents のサンプル」と入力する
3. 「追加」ボタンをクリックする

**Expected Results:**

- 入力したタスクが一覧に表示される
- 入力欄が空に戻る
